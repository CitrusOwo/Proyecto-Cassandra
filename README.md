# Proyecto-Cassandra
Aplicación web estructurada con templates HTML y archivos estáticos CSS, orientada a la visualización de cursos y página principal. Proyecto desarrollado con fines educativos y de aprendizaje en desarrollo web.

▶️ Cómo ejecutar el proyecto
Clonar el repositorio
git clone https://github.com/tu-usuario/tu-repositorio.git
Abrir la carpeta del proyecto
cd tu-repositorio
Abrir el archivo index.html en el navegador
